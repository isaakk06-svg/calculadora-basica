\# Calculadora Básica



\## Descripción



Este proyecto consiste en una calculadora básica desarrollada como una página web utilizando HTML. Permite ingresar dos números y realizar operaciones matemáticas básicas.



\## Objetivo



Desarrollar una calculadora sencilla como práctica para aplicar conceptos de desarrollo web y utilizar Git y GitHub para controlar las diferentes versiones del proyecto.



\## Funcionalidades



\- Ingreso del primer número.

\- Ingreso del segundo número.

\- Operación de suma.

\- Operación de resta.

\- Operación de multiplicación.

\- Operación de división.

\- Visualización del resultado.

\- Presentación de la versión del proyecto.



\## Tecnologías utilizadas



\- HTML

\- Git

\- GitHub

\- Bloc de notas



\## Estructura del proyecto



El proyecto contiene los siguientes archivos principales:



\- `index.html`: contiene la estructura y contenido de la calculadora.

\- `.gitignore`: contiene los archivos y recursos que no deben ser incluidos en el repositorio.

\- `README.md`: contiene la documentación del proyecto.



\## Instalación o ejecución



1\. Clonar o descargar el repositorio.

2\. Abrir la carpeta del proyecto.

3\. Abrir el archivo `index.html` en un navegador web.

4\. Utilizar la calculadora.



\## Historial de versiones



El proyecto ha sido desarrollado progresivamente mediante diferentes commits utilizando Git. Cada commit registra una mejora o modificación realizada durante el desarrollo.
